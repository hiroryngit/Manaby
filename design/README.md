# デザインシステム《朱と罫》

manaby の見た目は、題材そのもの — **ノートと添削** — から引いている。
中心にある成果物の名前が「AI分析ノート」であり、講師がやっているのは授業の添削記録だから。

実体は `src/theme.ts`（トークン）と `src/components/ui.tsx`（部品）。
画面の中で色を直に書かない。`#` から始まる値が `src/theme.ts` 以外に現れたら、それは違反。

---

## 層は3つしかない

| 層 | 何を担うか | 色 |
| :--- | :--- | :--- |
| **紙** | 面。罫で区切る。影では浮かせない | `paper` `sheet` `rule` `ruleDeep` |
| **鉛筆（藍）** | 記録された数値。理解度・集中度・評価・件数 | `ao` `aoMid` `aoWash` |
| **朱** | 講師と AI の書き込み | `shu` `shuWash` |

文字と主要操作は墨（`sumi`）。青いブランド色は持たない。
success の緑もアクセントの琥珀も持たない。彩度の高い色は朱だけ。

## 朱の規約（最重要）

朱は署名要素であって装飾ではない。**「目立たせたい」という理由で使ってはいけない。**
使ってよい先はこれだけ:

1. `<Annotation>` — 講師・AI が書いた文章の左に立つ傍線
   （AI分析ノート本文 / 生徒へのメッセージ / 指導方針 / 講師コメント）
2. `<Card mark>` — その中身が上記の文章へつながる場合
3. 理解度 2 以下の単元（`needsAttention()`）
4. 記録未入力・宿題未着手の督促
5. 講師側のタブと確定操作（`Button variant="mark"`）— 講師は書き込む側だから

**保護者・生徒側は墨と藍で読む側、講師側は朱で書く側。** これがロールの見分けになっている。
講師識別のための専用色（旧 `colors.tutor`）は廃止した。

**管理者は書く側でも読む側でもなく捌く側**なので、朱を持たない。タブも操作も墨で組む。
朱が出るのは「保護者未設定」「承認待ち」のように**手を入れないと止まる**箇所だけ
（規約4の督促と同じ扱い）。管理者は役割ではなく属性なので、専用の色も持たない。

## 書体

| 役割 | 書体 | 使う場所 |
| :--- | :--- | :--- |
| `display` `h1` | 明朝 | 画面の名乗りとレポートの見出しだけ。18pt 未満では使わない（潰れる）。太らせない（和文明朝の bold は濁る） |
| それ以外すべて | ゴシック | 本文・ラベル・数値 |
| `num` `numLg` | ゴシック + `tabular-nums` | 日付・件数・点数。桁が揃うことに意味がある値 |

数値専用の等幅書体は**持たない**。この画面の「データ」は `5問 ・ 期限 7月29日` のように
和文と数字が同じ行に混ざるため、欧文等幅を当てると数字だけ別の書体に落ちて行がばらつく。
桁を揃える目的は `fontVariant: ['tabular-nums']` で足りる。

## 面と形

- 角丸は `radius`（2 / 3 / 5 / 7）。ノートと記入用紙は角が立っている。
- 影は原則使わない。`shadow.lift` を使ってよいのは**画面につき1枚**。
  現状は保護者ダッシュボードの「今日やること」だけ（受け入れ基準そのものなので）。
- 区切りは `<Rule>` かカードのヘアライン。
- 検印（`<Badge>`）と選択の印は角を立てる。丸い錠剤・丸いラジオは使わない。
- 1行の入力は箱ではなく下の罫（`<Input>`）。複数行だけ罫で囲う。

## 取り消せない操作と、失敗の見せ方

- 元に戻せない操作の前には `confirmDestructive()`（`src/dialog.ts`）を挟む。
  ただし**失うものが無いときは呼ばない** — 何も起きない確認は次から読まれなくなる。
  例: 下書きの書き直しは、編集中の差分があるときだけ確認する。
- 失敗はダイアログではなく**操作した場所の隣**に出す。
  どの行の話か分からなくなるので、一覧の中の操作は必ずその行に出す。

## 空の状態

`<Empty>` には、次にできることが1つでもあるなら `action` を渡す。
逆に利用者にできることが本当に無い場合（講師が1人も登録されていない等）は渡さない。
押しても何も進まないボタンを置く方が不親切になる。

## 色に判別を負わせない

理解度は **線の濃さ（`pencilInk`）＋バーの長さ＋数値** の3つで読める。
レーダーチャートも、2以下の頂点は色に加えて点を大きくしラベルを太字にしている。

## 対応していないもの

- **ダークテーマ**。画面が静的 `StyleSheet.create` 前提で組まれているため、
  動的テーマ化は別作業として切り出す。`colors` を Context 経由に変える必要がある。
